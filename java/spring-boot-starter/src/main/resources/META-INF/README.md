# Inteagle VDM MQTT Spring Boot Starter

This artifact declares dependencies and does not define Java APIs.

- `vdm-mqtt-sdk`: `VdmMqttGateway`, protocol models and device RPC APIs.
- `vdm-mqtt-paho`: default and shared-connection Eclipse Paho transports.
- `vdm-mqtt-spring-boot-autoconfigure`: `VdmMessageListener`, configuration and lifecycle integration.

Source and API documentation are attached to those artifacts.
Usage: https://github.com/inteagle-vision/inteagle-vdm-mqtt-examples/tree/main/java
